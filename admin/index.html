發布流程與權限

  1. 使用已獲授權的 GitHub 帳號登入。網站管理權限由儲存庫管理員控管。
  2. 點選上方「編輯」，修改對應檔案；JSON 檔案務必維持正確格式。
  3. 先使用 GitHub 分支／Pull Request 審核重要內容，再合併至 main 發布。
  4. 檢查 GitHub Actions 與正式頁面，確認部署完成。

後續要達成類似 HANA SCENT 的「站內表單直接修改、儲存與審核」，需配置 OAuth 登入及有權限驗證的伺服器端寫入服務；目前這裡尚未提供該功能。
